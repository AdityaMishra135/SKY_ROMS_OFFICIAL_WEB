
# Redmi 12 5G / Poco M6 Pro 5G Community Hub

A premium platform for custom ROMs, modules, and developer tools for Sky devices.

## Features
- **Custom ROMs**: Verified system builds with performance optimizations.
- **Module**: Curated Magisk and Kernel extensions.
- **Root Protocol**: Official root packages with step-by-step guides.
- **Visuals**: High-fidelity Wallpapers and Live Visuals (MP4).
- **Admin Terminal**: Solar Yellow / Obsidian Dark themed administrative access.

### Core Features Built
- Custom ROM management system
- Firebase authentication and real-time database
- AI-powered content extraction (Genkit)
- Admin terminal with theme management
- Wallpaper and media gallery system
- Root protocol guide system

## Technical Specifications
- **Next.js 15 (App Router)**
- **Firebase (Auth & Firestore)**
- **Tailwind CSS & ShadCN UI**
- **Genkit (AI Extraction Engine)**
